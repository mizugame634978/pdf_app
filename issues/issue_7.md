# #7 透かし・ページ番号の追加ツールの実装

## 概要

PDFの各ページにテキスト透かしまたはページ番号を追加するツールを実装する。

## 背景

DESIGN.md 将来の拡張候補「透かし・ページ番号の追加（pdf-lib で対応可能）」に対応。

## やること

- トップ画面に「透かし / ページ番号」カードを追加する
- `src/lib/watermark.ts` を実装する
  - `addTextWatermark(buffer, text, options)`: 任意テキストを全ページに描画
  - `addPageNumbers(buffer, options)`: ページ番号を全ページのフッターに追加
- `src/components/ToolPanel/WatermarkTool.tsx` を作成する
- オプション設定UI:
  - テキスト入力
  - フォントサイズ・色
  - 配置（中央 / 左下 / 右下）
  - 透明度（透かしの場合）

## 技術メモ

- pdf-lib の `page.drawText()` で実装できる
- pdf-lib の組み込みフォントは英数字のみ。日本語テキストを使う場合は外部フォント（TTF）の埋め込みが必要
- 初期実装は英数字のみ対応とし、日本語対応は別 issue に分ける方針でも可

## 受け入れ条件

- [ ] 指定したテキストが全ページに透かしとして追加される
- [ ] ページ番号を指定した位置に追加できる
- [ ] 処理後のPDFをダウンロードできる
- [ ] 日本語入力したときの挙動（文字化け等）をユーザーに通知する
