# #9 PDFフォーム入力ツールの実装

## 概要

フォームフィールドが含まれるPDF（AcroForm）にブラウザ上でテキストを入力し、保存できるツールを実装する。

## 背景

DESIGN.md 将来の拡張候補「フォーム入力」に対応。
申請書・アンケートなどのPDFフォームをブラウザ上で記入したいケースに対応する。

## やること

- `src/lib/form.ts` を実装する
  - `getFormFields(buffer)`: フォームフィールドの一覧（名前・種別・位置）を取得する
  - `fillForm(buffer, values)`: フィールド名をキーにした値オブジェクトを受け取り、フォームに入力する
- `src/components/ToolPanel/FormTool.tsx` を作成する
  - PDFをアップロードするとフォームフィールドの入力欄が動的に生成される
  - テキストフィールド・チェックボックス・ラジオボタンに対応する

## 技術メモ

- pdf-lib の `PDFForm` API で AcroForm を操作できる
- フォームなしのPDFをアップロードした場合は「フォームフィールドが見つかりません」と表示する
- 電子署名フィールドは初期スコープ外

## 受け入れ条件

- [ ] フォームフィールドがあるPDFをアップロードすると入力欄が表示される
- [ ] テキストフィールドに入力してダウンロードすると値が反映されている
- [ ] チェックボックス・ラジオボタンを操作できる
- [ ] フォームなしのPDFをアップロードしたときに適切なメッセージを表示する
